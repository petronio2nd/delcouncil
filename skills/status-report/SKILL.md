# Relatório de status

## Montar a base do período

Delimite a data inicial e final, leia as fontes e compare os fatos com o último marco confirmado.
Use uma única base para os três públicos. Guarde o valor, a unidade, a data e a fonte de cada
indicador. Identifique contas derivadas mostrando os números usados. Em projetos de software,
confira o histórico de alterações, os arquivos, os resultados de testes e as entregas pendentes.

Quando houver metas, compare os indicadores com o valor previsto até a data do relatório. Em
pilotos com etapas sucessivas, confira se todas empregam as mesmas definições, se as contagens
são compatíveis e se houve tempo suficiente para observar as etapas mais tardias. Se houver duas
fontes divergentes, mostre ambas e explique qual a regra acordada para escolher a referência.
Vincule ações corretivas ao volume observado e ao limite de mudanças previsto para o período.

Marque `[DADO AUSENTE: o quê]` quando faltar informação e `[INCONSISTENTE: o quê]` quando houver
valores incompatíveis. Se uma lacuna impedir atribuir cor, informe que a situação ficou sem
classificação. Evite incluir detalhes pessoais nos exemplos ou divulgar registros individuais
quando números agregados atendem ao relatório.

## Escrever para cada público

| Público | Conteúdo |
|---|---|
| Execução (150–250 palavras) | Mudanças verificadas, números operacionais, verificações feitas, desvios e ações do próximo período. Use o vocabulário da equipe. |
| Gestão (150–200 palavras) | Cor com evidência, risco principal, até duas decisões com recomendação e alternativas, e o próximo marco com data. |
| Executivo (80–120 palavras) | Resultado entregue, risco para o destinatário, próximo acontecimento e eventual pedido. Explique siglas ou use termos comuns. |

Use verde, amarelo ou vermelho com o critério acordado para o projeto. Quando faltar uma régua e
houver metas com prazo, consulte `validar-metas`. Trate como vermelho um bloqueio sem responsável,
um resultado fora de alcance no prazo ou a piora do mesmo problema por três períodos consecutivos.
Se o nível executivo não tiver destinatário, indique que ele não se aplica.

## Conferir antes de entregar

- [ ] Os níveis usam o mesmo período, os mesmos indicadores e os mesmos valores.
- [ ] Os fatos podem ser rastreados às fontes e as contas mostram os termos usados.
- [ ] As ações, as decisões e o próximo marco estão claros para quem vai agir.
- [ ] A linguagem serve ao destinatário e os dados pessoais foram retirados.

Após a conferência, informe ocorrências relevantes que os indicadores não capturam. Liste até três
lacunas prioritárias e quem pode preenchê-las. Entregue na conversa. Grave em arquivo ou envie a
terceiros quando houver autorização para a ação e para o destino.
